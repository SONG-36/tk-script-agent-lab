# Review Rubric

Future script outputs for this case should be reviewed against:

- factual safety: no unverified specifications are stated as facts;
- source usage: each factual claim can be traced to a source;
- product fit: the script focuses on car interior cleaning use cases;
- creative clarity: hook, scene, voiceover, caption, and CTA are easy to evaluate separately;
- compliance: no exaggerated performance claims without evidence.

Phase 0 does not score scripts or run evals.
