# RAG Retrieval V1 Golden Case

This fixture is synthetic and non-official. It is designed only for deterministic
Phase 4B retrieval tests and demos.

It covers:

- stage filtering;
- market filtering;
- product category filtering;
- effective date filtering;
- exact phrase and term matching;
- ranking and limit behavior;
- forbidden retrieval checks.

The fixture does not represent TikTok policy and does not contain real secrets,
personal data, embeddings, or vector index data.
